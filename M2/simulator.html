Conversion handbook

What changes when we convert?

An ε-NFA is a nondeterministic finite automaton. A state can have zero, one or several destinations on a symbol. An ε arrow can be followed without reading any input. A word is accepted if at least one path reads the whole word and ends in an accepting state.

A DFA is a deterministic finite automaton. Each state has exactly one destination for each input symbol. Each arrow consumes one symbol. In the converted DFA, one state represents the entire set of ε-NFA states that could be active after the same input.

How to convert any given ε-NFA

  1. Read the diagram. List the states and input alphabet. The incoming start arrow identifies the start state. Double circles mark accepting states.
  2. Make the ε-NFA table. Give each state a row and each input symbol a column. Add an ε column. For each cell, collect the destinations of all matching outgoing arrows. Write ∅ if there are none.
  3. Find the start subset. Begin with the start state and follow every chain of ε arrows. Include the starting state itself. Visit each state once so cycles terminate. This set is its ε-closure. Name it D0.
  4. Fill one DFA cell. Pick a subset S and an input symbol. Collect the destinations on that symbol from every state in S. This union is the move. Take the ε-closure of the move to include all states reachable after consuming that symbol.
  5. Register the destination. If the resulting set already has a name, reuse it. Otherwise name it D1, D2, and so on, and add a row. If ∅ is reached, give it a row too. Every symbol from ∅ leads back to ∅.
  6. Finish the table and diagram. Process every symbol of every newly added row until all cells are filled. The DFA table has one column per input symbol. Mark D0 as the start and mark every subset containing an original accepting state as accepting. Draw one labeled arrow per cell.
