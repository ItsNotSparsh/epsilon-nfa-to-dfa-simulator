# Example 1 — Basic epsilon closure
states: q0, q1, q2
alphabet: a, b
start: q0
accepting: q2
transitions:
q0, eps, q1
q1, a, q1
q1, b, q2
q2, b, q2
expected: D0={q0,q1}; D1={q1}; D2={q2}; D3=∅. ab accepts; ba rejects.

# Example 2 — Epsilon branching
states: s, p, q, f
alphabet: a, b
start: s
accepting: f
transitions:
s, eps, p
s, eps, q
p, a, f
q, b, f
expected: start closure={s,p,q}; both a and b reach an accepting subset.

# Example 3 — Epsilon cycle
states: p, q, r, f
alphabet: 1, 0
start: p
accepting: f
transitions:
p, eps, q
q, eps, p
q, 1, r
r, 0, f
expected: E({p})={p,q}; cycle terminates. Input 10 accepts.

# Example 4 — Trap state
states: u, v, w
alphabet: a, b
start: u
accepting: w
transitions:
u, a, v
v, b, w
expected: missing moves reach ∅ only when required. Input ab accepts.

# Example 5 — Ends in ab
states: s, scan, lastA, end
alphabet: a, b
start: s
accepting: end
transitions:
s, eps, scan
scan, a, scan
scan, b, scan
scan, a, lastA
lastA, b, end
expected: ab, bab, babaab accept; aba, abb and empty input reject.

# Example 6 — Even number of 1s
states: s, even, odd
alphabet: 0, 1
start: s
accepting: even
transitions:
s, eps, even
even, 0, even
even, 1, odd
odd, 0, odd
odd, 1, even
expected: empty input, 000, 101 and 10100101 accept; 10 and 111 reject.
